# Roadmap

> Ideas and suggestions are welcome on [Discussions](https://github.com/PenglongHuang/chinese-novelist-skill/discussions) — your feedback sets the priorities.
>
> For the detailed changelog see [Releases](https://github.com/PenglongHuang/chinese-novelist-skill/releases).

## Done

- **v2.3.1** — fact-ledger rules, quantitative AI-flavor check, centralized chapter checklist, hardened word-count script
- **v2.3** — Infistar sponsor deal, MIT LICENSE / FUNDING / community sections
- **v2.1** — Layer 3 novel-title generation, seven styles of chapter-opening lead-in, fixed character-set details getting lost during drafting, unified project-file numbering
- **v2.0** — three-layer progressive Q&A, preference-memory system, interrupted-resume, three writing modes, Phase 4 auto-validation
- Style-baseline mechanism (fixes cross-chapter style drift), glossary management (introducing new concepts)
- Ongoing strengthening of the per-chapter de-AI-flavor rules (banning "not…but…" constructions and the like)

## In Progress

- **Visualization panel** — visualize the writing process: progress, word-count trend, validation results at a glance, no more scrolling through logs
- **FAQ** — compile the frequently asked questions: a self-check list for failed installs, interrupted-resume not triggering, falling short of the word count, preference memory resetting, and so on
- **Short-story mode** — a lightweight pipeline for pieces under ~10k words: trimmed Q&A, compressed validation, so short pieces don't need to run the whole long-form pipeline
- **Imitation writing** — supply a sample passage or an author-style sample, auto-extract the style fingerprint, then write in that style

## Planned

- **DSH plugin** — adapt for DeepSeek Harness (DSH) so users on DeepSeek-family models can drive this skill's complete workflow directly
- **RSI-Novel** — explore integration with RSI-Novel (form still to be determined)
